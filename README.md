# powerbi-ecommerce-sales-dashboard

## About the Project

This project is a simple Power BI dashboard created to analyse ecommerce sales data and understand sales, quantity, profit, customers, payment methods, and product performance.

I created this dashboard as part of my Power BI and data analytics practice. The main purpose was to work with raw sales data, create useful visualizations, and understand how business information can be presented through an interactive dashboard.

## What This Dashboard Shows

The dashboard provides an overview of ecommerce sales through different views:

- Total sales amount
- Total quantity sold
- Total profit
- Average Order Value (AOV)
- Sales by customer
- Quantity by product category
- Profit by month
- Sales by state
- Quantity by payment mode
- Profit by sub-category
- Quarterly filtering
- State filtering

## Key Metrics

The dashboard includes the following main KPIs:

- **Total Sales Amount:** 23K
- **Total Quantity:** 290
- **Total Profit:** 1,958
- **Average Order Value:** 6664

These values change based on the filters selected in the dashboard.

## Dashboard Visuals

### Sales by Customer

A bar chart is used to compare the sales amount generated by different customers.

### Quantity by Category

A donut chart shows the quantity distribution across product categories such as:

- Clothing
- Furniture
- Electronics

### Profit by Month

A column chart shows how profit changes from month to month. This helps in identifying months with higher or lower profit.

### Sales by State

The dashboard provides a state-wise view of sales.

### Quantity by Payment Mode

A donut chart shows the distribution of orders based on different payment methods, including:

- COD
- UPI
- Debit Card
- Credit Card
- EMI

### Profit by Sub-Category

A horizontal bar chart compares profit across different product sub-categories.

## Filters

The dashboard includes interactive filters that allow the user to explore the data based on:

- Quarter
- State

Selecting a filter updates the dashboard visuals accordingly.
